# MixCanvas 1.9.0 — Four tracks, WAV/FLAC and dark mode

MixCanvas 1.9.0 adds a fourth stereo track, WAV and FLAC imports, vertical
scrolling and a matte graphite dark theme.

## Download

Download `MixCanvas-1.9.0-portable.exe` from this release's assets. It is a
single Windows executable; no installer is needed. Keep it in its own folder
so MixCanvas can store its library and working files beside it.

The Microsoft Edge WebView2 Runtime is required. Windows 11 and most Windows 10
systems already have it; the Edge browser itself is not required.

Verify the download in PowerShell:

```powershell
Get-FileHash .\MixCanvas-1.9.0-portable.exe -Algorithm SHA256
```

SHA-256: `3C87F0DCE4A415FC0A9E5896717B5A901EE03911F0095BA695CC386147E08182`

## A fourth track: D

Arrange your mix across four stereo tracks: A, B, C and D. The new track has
the same clip editing, automation, effects, mute and solo controls as the
others, including its own row of Mix FX pads in the console.

Existing three-track sessions gain an empty track D.

## WAV and FLAC imports

Import **MP3, WAV and FLAC** using **+ AUDIO**, **Add Folder**, or drag-and-drop.
Mixed folders work too, with duplicate detection and unreadable-file reporting.

All three formats use the same preview, waveform, beatgrid, mixing and project
workflow. Artist and title tags are read from MP3 ID3, WAV INFO and FLAC tags
when available. Original files stay in their original format and are never
modified.

## Vertical scrolling

Tracks keep enough height to edit comfortably. Scroll down to reach D while
the transport and horizontal navigator stay visible.

| Gesture | Action |
| --- | --- |
| Mouse wheel | Scroll up or down through the tracks |
| Ctrl + wheel | Zoom the timeline |
| Shift + wheel | Scroll horizontally |
| R / T | Zoom out / in |

Track controls, clips and automation scroll together, so editing and
drag-and-drop still target the track under the pointer.

## Light and dark themes

The small moon/sun button beside **HELP** switches between the light aluminium
console and the matte graphite dark theme. The library, waveforms and editing
dialogs follow the selected theme. Your choice is remembered between launches.

## Upgrading

- Existing libraries upgrade automatically, and older `.mixcanvas` projects
  still open.
- Newly saved projects use format 2. MixCanvas 1.9.0 or later is required to
  open them; older releases cannot open the upgraded library either.
- Keep a backup of your `.mixcanvas` files and the **MixCanvas Files** folder
  before upgrading if you need to return to an earlier version.

All audio processing stays local. No account, telemetry or network connection
is required.
