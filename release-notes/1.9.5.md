# MixCanvas 1.9.5 — Song insertion, original speed and timeline search

MixCanvas 1.9.5 makes it easier to rearrange a mix, leave selected songs at
their original speed, and find a song in a long timeline.

## Download

Download **MixCanvas-1.9.5-portable.exe** from this release's assets. It is a
single Windows executable; no installer is needed. Keep it in its own folder
so MixCanvas can store its library and working files beside it.

The Microsoft Edge WebView2 Runtime is required. Windows 11 and most Windows 10
systems already have it; the Edge browser itself is not required.

The companion **MixCanvas-1.9.5-SHA256SUMS.txt** contains the download checksum.
Verify the executable in PowerShell:

```powershell
Get-FileHash .\MixCanvas-1.9.5-portable.exe -Algorithm SHA256
```

## Insert a song before or after an existing clip

Drag a song's **name or + button** from the Library onto a clip in the timeline.
Choose **Insert before**, **Insert after**, or **Cancel** in the dialog. It
names both songs and shows how far the following mix will move.

Following clips on all four tracks move together with their tempo points and
all automation: volume, pan, filter, reverb, flange, crush and delay. The
existing clip is kept. **Ctrl+Z** undoes the entire insertion in one step;
Cancel leaves the mix untouched. Clicking a Library song name still previews it.

## Original-speed playback per song

Right-click a song's **BPM in the Library** to disable or enable tempo matching.
The **Beatgrid Editor** has the same ON/OFF toggle, which takes effect immediately.

With matching **OFF**, the song plays at its original speed without
time-stretching and stops contributing a target to the mix's tempo curve.
The setting applies to every use of that song. Its analyzed BPM and beatgrid
are kept, and **FREE** appears beside its Library BPM.

Clip durations, waveforms, trims, loops, insertions and bounces follow the
selected playback mode. If changing mode would overlap clips on the same
track, make room before trying again.

## Find songs in the timeline

Use the discreet **magnifier below Undo/Redo** to search by title, artist or
filename. Search ignores case and accents and includes clips outside the
visible area.

Each occurrence has its own result, with its sequence number, track and
visible starting bar. Selecting a result brings that clip into view and
highlights it, scrolling vertically to its track when needed. Playback keeps
its current position.

Use **arrow keys and Enter** to select a result, or **Escape** to close search.

## Upgrading and project compatibility

- Existing `.mixcanvas` projects still open, with tempo matching enabled by
  default for songs saved by older releases.
- Projects containing a Library song with tempo matching disabled use
  **format 3** and require **MixCanvas 1.9.5 or later**.
- Projects with matching enabled for every Library song keep format 2,
  compatible with 1.9.0 or later.
- The local Library upgrades automatically to **schema 41**. Older executables
  cannot open that upgraded Library. Back up your **MixCanvas Files** folder
  and `.mixcanvas` projects before upgrading if you need to return to an
  earlier release.

All audio processing stays local. Original audio files are never modified.
No account, telemetry or network connection is required.
