# MixCanvas 1.8.2

This release brings the bounce improvements tested in 1.8.1-beta4 to the stable version.

## Download

Download `MixCanvas-1.8.2-portable.exe` from this release's assets. It is a
single Windows executable; no installer is needed. Keep it in its own folder
so MixCanvas can store its library and working files beside it.

Verify the download in PowerShell:

```powershell
Get-FileHash .\MixCanvas-1.8.2-portable.exe -Algorithm SHA256
```

SHA-256: `E6EE929B127B28A8554E6833A0A6B9C32496D8955B51CC40F691E500BE61FACC`

The Microsoft Edge WebView2 Runtime is required, but the Edge browser is not.
The executable is not code-signed, so Windows may show a SmartScreen warning.

## Normalize before limiter

The Bounce dialog now offers **Normalize before limiter**, on by default when
mastering is enabled. MixCanvas measures the whole stereo mix and applies one
constant gain before the look-ahead limiter. It never changes the balance
between tracks, and its automatic boost is capped at +12 dB. The bounce result
shows the normalization gain and the limiter's maximum gain reduction.

This is peak normalization, not loudness (LUFS) matching. It makes better use
of the limiter without promising that every mix will sound equally loud.

## Cleaner mastering path

The mastered bounce no longer passes through the playback monitor's fixed
output bound before reaching the offline limiter. Peaks are kept in float32
until the limiter handles them. Normal playback still keeps its protective
bound.

No project-file format or library database migration is required for 1.8.2.
